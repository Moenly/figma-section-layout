# 行程 Section 的实测样本

下列数字是从「走走小程序 → 2.0 方向探索 → 行程」画布读取的局部坐标。用于理解层级和区分现状与整理目标；在其他文件使用时直接读取目标文件的节点与样式。

| 分类行 | 模块 |
|---|---|
| 首页与创建 | 行程首页、创建行程 |
| 查看行程 | 行程概览与地图、SOS、单日与愿望清单、地点详情与导航 |
| 编辑行程 | 编辑模式、添加与替换地点、移动、复制与删除、增加一天与备注 |
| 同行协作与设置 | 共享相册、分享与邀请、设置与成员管理 |
| 参考与组件 | 局部样式与历史参考、行程复用组件 |

- **分类卡**实测 375 × 812，五行左边均为 x = 193，标题居中，48 px MiSans Bold，圆角 24。五行分别使用紫、蓝、绿、黄和灰。目标设计稿已有分类卡时复制其样式。
- **模块标题**共 15 个，包括直接命名为 SOS 的粉色标题。常规高度 120 px，文字靠左、垂直居中，左内距 48 px，字号 48 px。两张 375 px 画框组成一组时，标题宽 375 + 120 + 375 = 870 px。
- **子组**如「替换地点」「好友加入的视角」「同行者视角」。三个独立子组条实测高 72 px，文字 32 px。编辑行的「替换地点」标题与首框同在 x = 5128，跨两张画框，总宽 870 px；上一组末框右边在 x = 4888，净距 240 px。
- **组内与组间**在编辑行，分类右边是 x = 568，第一张画框从 x = 808 开始，相差 240 px。下一张从 x = 1303 开始，相对前框右边 x = 1183 留 120 px。编辑模式的末框右边 x = 1678，下一模块从 x = 1918 开始，净距 240 px。
- **标题与各行**五行画框顶线依次为 y = 521、2787、5644、8115、11606。15 个标题到对应顶线的实测净距分布为 125 px × 8、225 px × 4、263 px × 2、293 px × 1。源稿的行间留白有差异。本次统一后的模块条底边到画框顶边为 240 px，历史样本的间距仅供追溯；跨大分类统一使用 480 px，自上一排最低内容（含 Remark）量到下一排最高模块标题。
- **Remark**共识别 48 个画板备注容器。按同列所属画框量取，统一前有 25 处为 48 px，5 处为 64 px，其余为 55–86 px 的其他值。现已回读确认，48 处均为纵向自动布局、HUG 高度，距所属画框 64 px；新稿沿用此值。五行分类卡、产品里的「日备注」、补充参考画面、独立评审文字和上方的子组标题分别保留其角色。
